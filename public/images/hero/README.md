# BU-GA Café — Hero Section Imagery

This directory holds the photography, emblem artwork, and still poster frames for the BU-GA Café Hero section.

---

## Required & Recommended Files

| File Name | Usage | Description |
|:---|:---|:---|
| `hero-poster.webp` | **Hero Video Fallback Poster** | High-resolution still frame of the Hero scene (espresso pull or warm salon ambiance) displayed before `hero-loop.mp4` loads or during reduced-motion mode. |
| `hero-emblem.webp` (or `.png`) | **Hero Insignia Crest** | Transparent high-res version of the BU-GA silver and green embossed filigree insignia. |
| `hero-mobile-bg.webp` | **Mobile Still Background** | Optimized vertical/square still image for low-bandwidth mobile environments. |

---

## Technical Specifications

1. **Resolution:** 
   - `hero-poster.webp`: `1920x1080` (or `2560x1440` for 2K displays), 16:9 aspect ratio.
   - `hero-mobile-bg.webp`: `1080x1920` (9:16 vertical ratio).
2. **Format:** **WebP** (`.webp`) recommended. PNG with alpha transparency for cut-out logos or emblems.
3. **File Size Target:** Under 250 KB for background stills.
4. **Art Direction:** Deep forest green velvet, warm espresso crema, gentle steam, and subtle metallic silver/copper specular reflections consistent with BU-GA's brand aesthetic.
